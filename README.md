# Swing Pack

**A modern, flat-design component library for Java Swing — built on top of FlatLaf.**

[![Maven Central](https://img.shields.io/maven-central/v/io.github.dj-raven/swing-pack?label=Maven%20Central)](https://central.sonatype.com/artifact/io.github.dj-raven/swing-pack)
[![License](https://img.shields.io/github/license/dj-raven/java-swing-pack)](LICENSE)
[![Stars](https://img.shields.io/github/stars/dj-raven/java-swing-pack?style=social)](https://github.com/dj-raven/java-swing-pack)

Swing Pack provides beautiful, customizable, and ready-to-use UI components for Java desktop
applications, so you can build modern-looking interfaces without writing them from scratch.

## Components

- [x] [Pagination](docs/components/pagination.md)
- [x] [Multi-Select ComboBox](docs/components/multi-select-combobox.md)
- [x] [DateTime Field](docs/components/datetime-field.md)

## Installation

```xml

<dependency>
    <groupId>io.github.dj-raven</groupId>
    <artifactId>swing-pack</artifactId>
    <version>{version}</version>
</dependency>
```

See the [installation guide](docs/index.md#installation) for Gradle setup and snapshot builds.

## Documentation

Full usage examples, properties, and API reference for every component are available in the
